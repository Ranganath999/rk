📖 How It Works

Upload Process:

  1. Select a file from your device
  2. Enter a strong passphrase (remember it!)
  3. File is encrypted locally using AES-256
  4. Encrypted file (.enc) is uploaded to cloud storage
  5. You receive a download link/ID

Download Process:

  1. Paste the file URL or ID
  2. Enter the same passphrase used for encryption
  3. Encrypted file is downloaded from cloud
  4. File is decrypted locally in your browser
  5. Original file is saved to your device
🔒 Security Features:
  • ✅ Client-side AES-256 encryption
  • ✅ Passphrase never sent to server
  • ✅ Server only stores encrypted data
  • ✅ SHA-256 integrity verification
  • ✅ Optional Firebase Authentication

🔐 Your privacy is our priority. All encryption happens in your browser.
